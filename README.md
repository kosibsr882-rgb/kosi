# Fast Mailer 🚀

A lightweight Node.js + Express app for sending emails via Gmail using Nodemailer. Includes simple login authentication and session management.

## Features
- 🔐 Secure login with session handling
- 📧 Send emails via Gmail (App Password required)
- 🎨 Simple frontend with login and launcher pages
- ⚡ Fast and minimal setup
